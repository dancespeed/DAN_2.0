# Чекпоинт: EEPROM как стандартный системный модуль

**Проект:** DAN Platform 2.0
**Дата:** 2026-07-30
**Статус:** реализовано и подтверждено на ATmega328P

## Зафиксированное решение

Стандартная сборка устройства содержит системный модуль EEPROM:

```text
device_modules.hpp
└── EepromModule
    ├── ModuleID 0x03
    ├── имя EEPROM
    └── platform::Eeprom
```

Конкретный состав устройства объявляется вне `core` и передаётся в
`System::Initialize()`. Ядро принимает список указателей на модули и их
количество, передаёт его в `Runtime`, а затем регистрирует модули в
`ModuleTable`.

Пустые позиции списка пропускаются. Ошибка регистрации непустого
модуля означает ошибку инициализации состава устройства.

## Контракт EEPROM

`EepromModule` использует зарезервированный системный `ModuleID 0x03`
и возвращает имя `EEPROM`.

На этом этапе `platform::Eeprom::Initialize()` проверяет только наличие
реального EEPROM по ненулевому значению `EEPROM.length()`.

Если EEPROM доступен, модуль успешно проходит `Initialize()` и
`Start()`, переходит в состояние `Running` и сообщает:

```text
Module 0x03 (EEPROM) ready
```

Если EEPROM отсутствует, модуль остаётся остановленным, строка
готовности не выводится, а запуск остальных модулей может продолжаться.

## Граница кирпичика

Этот чекпоинт не добавляет:

- чтение или запись EEPROM;
- формат хранимых данных;
- хранение или восстановление `GlobalID`;
- конфигурационные DAN-сообщения;
- `ConfigurationTable`;
- служебный DAN ping и тайм-аут готовности;
- другие модули стандартной сборки.

## Проверка

Пройдены:

- host-тест доступного EEPROM;
- host-тест отсутствующего EEPROM с объёмом `0`;
- проверка регистрации ID `0x03`;
- проверка перехода доступного модуля в `Running`;
- проверка точной строки `Module 0x03 (EEPROM) ready`;
- прежние lifecycle- и message-core host-тесты;
- строгая host-компиляция;
- `git diff --check`;
- PlatformIO-сборка среды `nanoatmega328`;
- загрузка прошивки и запуск на реальном ATmega328P.

Пользователь подтвердил 2026-07-30 следующий аппаратный вывод:

```text
[DIAG] Routing stage start
[BUS] Initialized
[DISPATCH] Initialized
[DISPATCH] Started
Module 0x03 (EEPROM) ready
[BOOT] System started
[MODULE] Run: EEPROM
```
