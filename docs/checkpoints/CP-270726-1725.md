# Checkpoint 0.1 — Core Runtime Stable

## Архитектура

Подтверждена следующая структура:

```text
System
 ├── Platform
 └── Runtime
      ├── ModuleTable
      ├── MessageBus
      └── MessageDispatcher
```

## Жизненный цикл

Полностью работает цепочка:

```text
Initialize()
      ↓
RegisterModules()
      ↓
InitializeModules()
      ↓
Start()
      ↓
Run()
      ↓
Stop()
```

Каждый модуль реализует:

```cpp
Initialize();
Start();
Run();
Stop();

Receive(const Message&);
```

через внутренние обработчики:

```cpp
OnInitialize();
OnStart();
OnRun();
OnStop();
OnReceive();
```

Проверена вся цепочка:

```text
Module
    ↓
MessageBus::Publish()
    ↓
FIFO
    ↓
MessageDispatcher
    ↓
ModuleTable
    ↓
Module::Receive()
    ↓
OnReceive()
```

Все звенья работают корректно.

# Diagnostics

Диагностика интегрирована в платформу.

Особенности:

* независима от Runtime;
* использует `Arduino Stream`;
* может быть включена и отключена;
* не влияет на heartbeat;
* каждый компонент отвечает только за собственные сообщения.

Принято правило:

* `Runtime` — только запуск Runtime;
* `ModuleTable` — только жизненный цикл модулей;
* `MessageBus` — только публикация и приём сообщений;
* `Dispatcher` — только маршрутизация;
* модули — только собственные события.

# Следующий крупный этап

Теперь можно переходить от проверки инфраструктуры к развитию платформы. Логичным следующим этапом я вижу не добавление новых модулей, а развитие самой модели обмена сообщениями:

1. **Диагностика `MessageDispatcher`** — отображать путь сообщения от отправителя к получателю.
2. **Расшифровка сообщений** — выводить не только отправителя и получателя, но и `ObjectId`, `MessageId` и `Value`.
3. **Объектная модель (`ObjectId`)** — начать формировать библиотеку объектов платформы (`System`, `Led`, `Button`, `Display`, `Sensor` и т.д.).
4. **Первые реальные сервисные модули** — например `LedModule` и `HeartbeatModule`, уже работающие исключительно через `MessageBus`.

Это будет естественным переходом от "проверенной инфраструктуры" к "реальной платформе".
