## Чекпоинт: модульная подсистема DAN

### Архитектура системы

```text
System
 ├── Platform
 └── Runtime
      └── ModuleTable
           └── Module
```

### Жизненный цикл

```text
Initialize()
Start()
Run()
Stop()
```

Порядок запуска:

```text
Runtime::Initialize()
    ↓
ModuleTable::Initialize()
    ↓
RegisterModules()
    ↓
ModuleTable::InitializeModules()
    ↓
Runtime::Start()
    ↓
ModuleTable::Start()
    ↓
Runtime::Run()
    ↓
ModuleTable::Run()
    ↓
Runtime::Stop()
    ↓
ModuleTable::Stop()
```

`Stop()` вызывается для модулей в обратном порядке регистрации.

## Базовый класс `Module`

`Module` является контроллером жизненного цикла.

Публичный интерфейс:

```cpp
void Initialize();
void Start();
void Run();
void Stop();

virtual ModuleId GetId() const = 0;
ModuleState GetState() const;
```

Конкретные модули реализуют:

```cpp
virtual bool OnInitialize() = 0;
virtual bool OnStart() = 0;
virtual void OnRun() = 0;
virtual void OnStop() = 0;
```

Автомат состояний:

```text
Stopped
   │ OnInitialize() == true
   ▼
Initialized
   │ OnStart() == true
   ▼
Running
   │ Stop()
   ▼
Stopped
```

Недопустимые вызовы игнорируются базовым классом.

При ошибке `OnInitialize()` модуль остаётся в `Stopped`.

При ошибке `OnStart()` модуль остаётся в `Initialized`.

## `ModuleTable`

Интерфейс:

```cpp
Initialize();
Register(Module&);
Find(ModuleId);

InitializeModules();
Start();
Run();
Stop();
```

Хранение:

```cpp
struct ModuleEntry
{
    Module* module = nullptr;
};
```

Используется статический массив:

```cpp
ModuleEntry modules[config::MaxModules];
```

Свойства:

* динамическая память не используется;
* повторный `ModuleId` не допускается;
* поиск линейный;
* регистрация происходит до инициализации модулей;
* все модули существуют к моменту `InitializeModules()`.

## Конфигурация Runtime

Файл:

```text
src/core/config/runtime_config.hpp
```

Текущее содержимое:

```cpp
#pragma once

#include <stddef.h>

namespace dan
{
namespace core
{
namespace config
{

inline constexpr size_t MaxModules = 32;

}
}
}
```

Для совместимости с AVR используется глобальный `size_t`, а не `std::size_t`.

## Идентификаторы модулей

Тип:

```cpp
using ModuleId = uint16_t;
```

Централизованный каталог:

```text
src/core/module/module_ids.hpp
```

Текущий идентификатор:

```cpp
namespace dan::core::ModuleIds
{
    inline constexpr ModuleId Test = 1;
}
```

Магические числовые идентификаторы из модулей удалены.

## Тестовый модуль

Расположение:

```text
src/modules/test/
    test_module.hpp
    test_module.cpp
```

`TestModule`:

* наследуется от `core::Module`;
* не хранит собственное состояние;
* не управляет переходами жизненного цикла;
* реализует только методы `On...`;
* возвращает `core::ModuleIds::Test`.
